# nextjs项目开发步骤

## 1. 项目开始准备工作

- 创建 Next.js 新项目 `npx create-next-app@latest my-book-app`
- 运行开发服务器 `npm run dev` 验证项目是否正常运行
- 清理默认样板代码，只保留必要的文件和目录
- 配置项目基础信息  修改网站元数据（SEO 标题、描述）、 配置网站图标 、配置字体、配置主题色、配置全局样式
- 安装常用必备依赖 clsx tailwind-merge dayjs 等等
- 创建常用文件夹结构 lib components utils hooks services pages components hooks services utils 等等
- 配置 Git
- 制定基础开发规范 如命名规范、代码规范、注释规范、提交规范等 可以写 agent skill

## 2. 项目基础配置

- 配置 Tailwind CSS
- 配置 ESLint Prettier 或者 Biome

## 3. 确认数据库相关的方案

- 是使用Neon 还是自建数据库
- 如果使用Neon 则需要确认数据库的类型 如使用 PostgreSQL 还是 MySQL
- 如果使用自建数据库 则需要确认数据库的类型 如使用 PostgreSQL 还是 MySQL
- 如果使用自建数据库 则需要确认数据库的连接方式 如使用 pg 还是其他
- 如果使用自建数据库 则需要确认数据库的表结构 如用户表、图书表、分类表、借阅记录表、书评表、轮播图表、推荐表、公告表等
- 如果使用自建数据库 则需要确认数据库的迁移方式 如使用 drizzle-kit 还是 prisma 还是其他
- 如果使用自建数据库 则需要确认数据库的迁移方式 如使用 drizzle-kit 还是 prisma 还是其他

## 4. 确认项目路由设计

- 确认用户端路由设计 如登录、注册、首页、图书列表、图书详情、收藏、借阅记录、通知、设置等
- 确认管理员后台路由设计 如数据看板、用户管理、图书管理、分类管理、借阅记录、书评审核、轮播图、推荐、公告等
- 确认公共路由设计 如404、500等
- 确认路由守卫 如登录守卫、权限守卫等
- 确认路由懒加载 如登录、注册、首页、图书列表、图书详情、收藏、借阅记录、通知、设置等
- 确认路由动态路由 如用户ID、图书ID、分类ID、借阅记录ID、书评ID、轮播图ID、推荐ID、公告ID等
- 确认路由动态路由 如用户ID、图书ID、分类ID、借阅记录ID、书评ID、轮播图ID、推荐ID、公告ID等
